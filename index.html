Projects

EduSense (Tempered-AI)

A platform that promotes intentional AI use among students and educators, built for an ODU software engineering course. Instead of handing over answers, it uses reflective prompts and challenge modes that delay AI assistance until a student has engaged with the problem themselves, plus usage analytics that let instructors see how students are actually using it. It integrates with Canvas to stay aware of academic context.

I built the full stack solo: a Django backend with REST API endpoints, a SQLite database for user and session data, a React frontend, and the input sanitization and model-handling logic behind the "responsible AI use" behavior.
