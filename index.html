About

I'm a graduate student pursuing a Master's in Computer Science, with a Bachelor's in Computer Science from Old Dominion University. Before software, I spent eight years in the U.S. Navy as a Nuclear Machinist Mate and Quality Assurance Supervisor, leading and training technicians in mission-critical environments where a missed step wasn't an option.

That background is where my interest in backend systems and reliability comes from: formal inspection, procedural compliance, and root-cause troubleshooting translate surprisingly directly into writing tests, reviewing code, and being the person who checks that the thing actually works before calling it done.

Projects

EduSense (Tempered-AI)

A platform that promotes intentional AI use among students and educators, built for an ODU software engineering course. Instead of handing over answers, it uses reflective prompts and challenge modes that delay AI assistance until a student has engaged with the problem themselves, plus usage analytics that let instructors see how students are actually using it. It integrates with Canvas to stay aware of academic context.

I built the full stack solo: a Django backend with REST API endpoints, a SQLite database for user and session data, a React frontend, and the input sanitization and model-handling logic behind the "responsible AI use" behavior.

DupDetector

A Java command-line tool that finds near-duplicate code across repositories using a custom tokenizer and hashing pipeline, with an automated report generator built on top. I expanded JUnit coverage and wired up GitHub Actions CI gates, and optimized the pipeline for large codebases.
